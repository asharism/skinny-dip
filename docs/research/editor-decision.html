The Mac editor is CodeMirror 6

Skinny Dip needed a Markdown editor with Sublime-style multi-cursor, fast on large files, under a license that keeps the project open. Three engines were built as evaluation apps and tried on the same 10,000-line document.

CodeMirror 6, running in a WKWebView

It is the only engine with ⌘D, add-cursor-above/below and ⌘-click built in, it is MIT-licensed, and it felt fastest in hand testing. It costs the most memory and needs a Swift↔JS bridge, both accepted.

Measured with footprint on macOS 27.0, Xcode 27.2. The spike apps' status bars show only the app process, which made CodeMirror look smallest. The live Preview needs a web view anyway, so some of this cost is shared (issue #9).

What we accept

  • We own the bridge between CodeMirror and macOS: undo and the document's edited state, Select All beyond the visible part, the Edit and right-click menus. MarkEdit, an MIT Mac editor built the same way, is the reference.
  • Spell check, autocorrect and Writing Tools come through WebKit, not the native text system. They were not scored one by one in the spike and get checked in the real app (issue #6).
  • WebKit input-method bugs and Writing Tools changes arrive with macOS releases. The three evaluation apps stay in Spikes/Editors/ so the comparison can be re-run.
  • Copy stays pure Swift (ADR-0001). The editor reports text and selection; it never writes the clipboard.
