# UI Shell canvas source

Source files of the design canvas drawn during the Nov 1, 2026 design session: https://claude.ai/artifact/VVfufRHyABMNDdp6W9GgQy (private to the owner). They need the canvas runtime to render. To view the design locally, open `../ui-shell-mockup.html` instead, a standalone copy with the same content.

The standalone mockup and `SkinnyDip/Resources/themes/*.json` are the source of truth for the values. The canvas predates two marker-color fixes (Sea Glass `#788d87`, Apricot `#988278`) made to reach 3:1 contrast.
