Skinny Dip — UI Shell mockup

Interactive mockup for docs/design/ui-shell.md: Tabs, two Cards, the Copy split button, scroll-sync toggle, render-option chips, and the eight themes. Click around; nothing is wired to real Markdown.

Themes

Four light/dark pairs. Match System switches between the halves of a pair. Each theme is one token file in SkinnyDip/Resources/themes/.
