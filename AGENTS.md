# AGENTS.md

All project guidance for AI agents lives in [`CLAUDE.md`](./CLAUDE.md). It is the single source of truth.

- **Reading:** whenever you need project context, commands, architecture or working agreements, read `CLAUDE.md`. Don't rely on this file for any of it.
- **Updating:** when guidance needs to change, edit `CLAUDE.md`. Don't add project guidance here or create parallel instruction files.
- **Building:** agents are fully in charge of implementation, builds, tests, and launching the app for verification. Do not delegate those steps to the user. Details: **Agent ownership** in `CLAUDE.md`.
